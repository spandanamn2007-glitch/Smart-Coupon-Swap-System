# Database Operations Guide: Smart Coupon Swap System

## 1. Environment & MySQL Version
- **Database Name**: `smart_coupon_swap`
- **Target RDBMS**: MySQL 8.x (compatible with MySQL 8.0 through 8.4+)
- **Storage Engine**: `InnoDB` (ACID transaction compliance, row-level locking, foreign key integrity)
- **Character Set**: `utf8mb4`
- **Collation**: `utf8mb4_unicode_ci`

---

## 2. SQL Scripts Purpose

### `database/schema.sql`
- Creates the `smart_coupon_swap` database safely if it does not exist.
- Defines all 17 normalized relational tables in Third Normal Form (3NF).
- Creates primary keys, foreign keys, unique constraints, domain check constraints, and performance indexes.
- Prepares the complete database structure required for both transactional operations and downstream Data Science telemetry.

### `database/seed.sql`
- Populates minimal reference and taxonomy seed data required to verify the schema.
- Inserts default roles (`ADMIN`, `USER`).
- Inserts 8 standardized retail categories and 10 recognized merchant brands.
- Inserts 3 non-production test accounts with dummy password hash placeholders for schema testing.
- **Note**: Does NOT insert large-scale datasets; the Data Science dataset will be generated during Phase 3.

## 3. How to Execute Scripts in MySQL Workbench

### Step 1: Open MySQL Workbench and Connect
1. Launch **MySQL Workbench**.
2. Open your local MySQL connection (e.g., `Local instance MySQL80` on port `3306`).

### Step 2: Execute `schema.sql`
1. In the top menu, go to **File** $\to$ **Open SQL Script...** (or press `Ctrl + Shift + O`).
2. Navigate to your project folder and select:
   ```
   smart-coupon-swap-system/database/schema.sql
   ```
3. Click the **Execute (Lightning bolt)** icon or press `Ctrl + Shift + Enter` to run the entire script.
4. In the **Output Panel** at the bottom, verify all `CREATE TABLE` statements show green checkmarks.

### Step 3: Execute `seed.sql`
1. Go to **File** $\to$ **Open SQL Script...**.
2. Select:
   ```
   smart-coupon-swap-system/database/seed.sql
   ```
3. Click the **Execute (Lightning bolt)** icon (`Ctrl + Shift + Enter`).
4. In the **Navigator** sidebar on the left, right-click inside the **Schemas** tab and select **Refresh All**. You will see the `smart_coupon_swap` schema with all 17 tables populated.

## 4. How to Execute Scripts via Command Line / Terminal

### Using Windows PowerShell / Command Prompt:
```powershell
# 1. Execute schema creation
& 'C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe' -u root -p -e "source database/schema.sql"

# 2. Execute reference seed data
& 'C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe' -u root -p -e "source database/seed.sql"
```

### Using Standard Bash / macOS / Linux:
```bash
# 1. Execute schema creation
mysql -u root -p < database/schema.sql

# 2. Execute reference seed data
mysql -u root -p < database/seed.sql
```

## 5. How to Verify Database Tables and Integrity

### Interactive Query Verification:
Run the following queries in MySQL Workbench or MySQL CLI:
```sql
USE smart_coupon_swap;

-- 1. View all created tables (should list 17 tables)
SHOW TABLES;

-- 2. Verify seeded reference counts
SELECT 'roles' AS table_name, count(*) AS total_records FROM roles
UNION ALL
SELECT 'categories', count(*) FROM categories
UNION ALL
SELECT 'brands', count(*) FROM brands
UNION ALL
SELECT 'users', count(*) FROM users;
```

### Automated Verification Script:
An automated test script is provided in `scripts/validate_database.py` that verifies table existence, foreign key enforcement, unique constraints, and check constraints:
```bash
python scripts/validate_database.py
```

## 6. Important Operational Notes
- **Security**: Never store plaintext passwords in `users`. Use bcrypt hashes generated by application services. Never commit database passwords or `.env` files to Git.
- **Monetary Precision**: Always use `DECIMAL(10, 2)` for discounts, min spend amounts, and savings. Never convert monetary columns to `FLOAT` or `DOUBLE`.
- **Foreign Key Safety**: Referential integrity is enforced with `ON DELETE RESTRICT` on core business entities to prevent accidental cascading data loss.
